# 涨跌语义三档切换：全局红涨退役，市场原生入场

日期：2026-11-16　状态：已采纳（主人提出需求并经 grilling 十一题逐项拍板；正式推翻 2026-11-15 detail-typography 评审 P1-3「涨跌色保持全局红涨、不做 per-market」——docs/plans/2026-11-15-detail-typography-overhaul-implementation-plan.md:11,38,516、docs/verification.md:958,963）

涨跌色此前是市场无关的全局常量：`--skc-up/down` 变量层（styles.mjs:44-45，A股惯例红涨绿跌）+ `trendClass(v)` 单参类名分发（fmt.mjs:63）+ SVG 侧模块常量 UP/DOWN（charts.mjs:14-15）。多市场自选（A股+港股+美股+加密）在同一插件内被迫接受单一口径，与各市场原生惯例相悖。本 ADR 确立三档可切换的涨跌语义模型。

**决定**：

1. **三档模型，默认红涨绿跌**（= 旧现状，升级零感知）：红涨绿跌 / 红跌绿涨 / 原生语义。单档全局生效，不做按系统 locale 自动选档。
2. **原生映射表**：cn 红涨绿跌；hk、us、crypto 绿涨红跌；指数随所属市场。港股按「交易所所在地惯例」归绿涨红跌（「主要参与者是内地资金」口径已裁决不采纳）。
3. **一处设置管全部语义色**：胶囊涨跌幅、列表行、持仓盈亏列、详情 hero、B/S 触价标记与徽章、分时图（线+量柱）、K 线（阳阴线+量柱）。盈亏不独立设置；详情持仓摘要素文本维持不着色；`--skc-danger`/`--skc-warn`/额度告警/MA60 均线色不动——**`--skc-danger` fallback 与 up 同 hex（#e5484d），实现禁按色值全局替换**。
4. **B/S 严格耦合**：买恒取涨色、卖恒取跌色，随档位换向；原生档按标的所在市场取色。
5. **平盘与无数据恒中性灰**（`skc-flat`），不参与换向。
6. **方向符号 ▲▼ 仅加在涨跌幅字段**（胶囊/列表行/hero 三处），平盘不加；价格与涨跌额维持现状——方向信息颜色+符号双编码（色弱冗余）。
7. **存储随 DSH 实例**（服务端 settings 层，非云无账号）：扩展 settings 路由与 normalizeGlobal schema。理由：被着色的数据（自选/持仓）本身随实例走，读数口径跟着数据走；rev 广播免费获得全量重渲染+图表重画；备份导出/导入天然携带。
8. **设置 UI**：设置对话框新增「涨跌配色」组——竖排 radio 三行、每行内嵌真实渲染预览（前两行展示涨跌对，原生行展示「同涨不同色」沪红/美绿），hairline-soft 分隔既有备份区；点选即时生效、无保存钮，写入失败回滚 + toast；radio 选中态用 accent，涨跌色只用于预览演示（延续「红色只留给涨跌与告警」纪律）。
9. **前提边界**：现设计四市场 Tab 单市场过滤（持仓开关在市场过滤后生效，list.mjs:445-446），同屏不混色；未来若引入跨市场同屏视图（如「全部」Tab/汇总页），混色体验议题重开。

## Considered Options

- **分段控件（`.skc-tabs` 语言现成）**：拒绝——装不下逐档副标与预览，选择与理解之间多一跳；radio 列表三行并排、后果同时可见，扫视效率最高（impeccable shape 裁决，Operate 模式）。
- **客户端 localStorage（ui 切片白名单）**：拒绝——清浏览器数据即丢、多浏览器访问同一实例口径漂移；实现需三处接线（UI_PERSIST_KEYS + list/panel structural 门控 + 图表重画触发），服务端 rev 广播一处免费全量。
- **B/S 解耦恒定买红卖绿**：拒绝——红跌绿涨档下 B(红) 与跌色撞车、视觉读作看跌；换固定配色对（蓝/橙）则引入第三种颜色语义，扩大改动面。
- **只做全局两档翻转（对 11-15 决策半推翻）**：拒绝——原生档是需求核心价值所在。
- **按 locale 自动选档**：拒绝——不可预期的行为切换，收益不抵。

## Consequences

- `trendClass` 加 market 维度（原生档「同屏不同市场不同向」的唯一分发入口）；调用点作用域内均持有 market 可传（capsule.mjs:417、list.mjs:333、detail.mjs:683 等）。
- SVG 侧 UP/DOWN 常量改走 style 属性 + `var(--skc-up/down)`（仓内先例 charts.mjs:19-22 AXIS_TEXT_STYLE），与 DOM 层统一由变量驱动；图表重画时机已有（structural 切片/maVisible），无需新增。
- 服务端三处 schema 同步：model.normalizeGlobal、settings 路由 patch 白名单、parseImportPayload（备份往返）；rev 自增与落盘复用既有管道（store.mjs:325-332）。
- i18n zh/en 双字典新增组标签/三档标签/副标文案（parity 守卫强制同步）。
- 类名缝教训适用：新类名与样式表逐字一致（前科：sk-up vs `.skc-up` 致红涨绿跌自 v0.1.0 静默失效，verification.md:148,157,169）；产物探针用 minify 免疫标记，中文字面量按 `\\uXXXX` 转义定串。
- 设计契约随实现修订：docs/ui-redesign.md A1（红涨绿跌）与 A2（买红 B/卖绿 S）条款改为「随涨跌语义档位」表述。
- 测试面：trendClass 三档×市场断言、settings 路由往返、radio 交互与 aria 语义、预览三行色对守卫、备份携带语义档位往返。

## 修订（2026-11-16 目验后）

- **决定 6 撤销**：方向符号 ▲▼ 上线后主人目验判定「UI 臃肿且丑」，拍板**全撤**（胶囊/列表/详情/设置页预览等一切位置）——恢复颜色单编码。`fmtTrendPct` 与三处调用点退役，相关测试断言随新规格更新。色弱冗余诉求如实记录：撤销属主人显式权衡（视觉密度 > 无障碍冗余），非疏漏。
- 其余决定（1–5、7–9）维持不变；本次目验同轮落地的 Q3（降级说明收 tooltip）与 Q4（hk 指数分时大小写修复）为缺陷修复，非决策变更，事件记录见 verification §12.65。
